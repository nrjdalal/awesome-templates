# Alembic Migration Management

Input: $ARGUMENTS

## Default Flow Position
See [target-operating-model §1](../../../docs/ai/shared/target-operating-model.md) — `migrate-domain` routing.

## Procedure Authority
Read and follow the [full procedure](../../../docs/ai/shared/skills/migrate-domain.md) before acting; it owns requirements, gates and outputs.

## Procedure Overview
1. Pre-check — verify alembic.ini, env file, Model file existence
2. Execute command — generate/upgrade/downgrade/status with appropriate options
3. Review — always review autogenerated files before applying, including the zero-downtime safety review (`tools/check_migration_safety.py` advisory, ADR 056)
4. Verify — check applied revision, run integration tests
